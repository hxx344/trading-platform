# 副服务器巡检心跳（R3）审查记录

- 批次：v0.47.0，方案与操作见 [../watch.md](../watch.md)。
- 等级：R3（新的凭据字段 `secrets.watch.token` 与配置字段 `watch`、`install.sh` 新开关、发布文件新增两个、另一台服务器上的 root 安装器）。

## 影响面与回滚（动手前）

- 用户可见行为：配了 `watch` 后，本服务每 30 秒向副服务器推送签名心跳；「运行状态」页多一栏。没配时行为不变。
- 涉及文件：`src/service/watch.ts`、`src/service/watch-config.ts`（新）；`src/runtime.ts`（`notReady`）、`src/service/config.ts`、`src/service/main.ts`；`web/src/StatusPage.tsx`、`web/src/types.ts`；`deploy/install.sh`、`deploy/package.sh`、`deploy/install-watch.sh`（新）、`deploy/main-watch/`（新）；两个工作流；测试与文档。
- 不碰：划转、ADL、原油、期权、资产、行情监控的逻辑；数据库结构；页面登录与 `/api/ready` 的鉴权边界。
- 失败时：推送失败只影响巡检告警（误报），不影响交易。配置写入失败或新配置启动失败时，`install.sh` 把两个文件恢复原样。
- 回滚：`sudo bash install.sh --watch-off`，再 `sudo bash install.sh --version v0.46.0`。副服务器 `sudo bash install-watch.sh --uninstall`，或留着（收不到心跳会告警）。
