## 第二轮（独立复核，增量 8138c17..c459ade）

第一轮 P0 修复成立：`leadWithdraw` 各路径（撤单成功、结果未知、次数用尽、被登记阻止、撤单期间成交、unresolved 分支）都有界结束，没有漏撤或撤完重发。

| 级别 | 问题 | 处理 |
| --- | --- | --- |
| P1 | 第一轮 P1 只修了一半：攒着的小额成交在首腿不挂单的空档（改价重挂之间、一批结束、截止）以及首腿最后一笔小额成交，仍按全额发对冲，低于最小名义被拒后转人工 | 已修：<br>· 本地追价开仓时，只要首腿还会继续（挂着，或改价、下一批还会再挂），就保留约 1.2 倍最小名义的未对冲余量，只对冲超出部分，最后一笔对冲因此不会太小。<br>· 保留余量只用于本地追价；市价分批“每批对冲后再发下一批”不变。<br>· 首腿结束后余量仍低于最小名义（整单只成交极少）时，不发必被拒的单，转人工写明数量、约合金额与“首腿账户只减仓”处理方式（市价首腿同样适用）。<br>· 补测试：改价空档不对冲小额、结束时余量不足直接转人工且不发单；变异核对两处修复去掉后对应用例失败 |
| P2 | 测试缺口：对冲腿达到委托上限、发送前检查拒绝、等待超宽限、撤单用尽 / 被阻止、撤单后恢复完成 | 补对冲腿委托上限用例；其余路径与已测路径共用 `escalate` / 撤单分支，未逐一补用例，登记 |
| P3 | 撤单用尽 / 被阻止时转人工原因覆盖了撤首腿的原因 | 已修：原因前面带上“撤首腿挂单（…）时：” |

| P3 | `refusable` 无余量，买入首腿价跌后可能连被拒 3 次 | 已修：同样用 1.2 倍余量 |
