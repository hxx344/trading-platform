# OKX 链上折价扫描与侧栏入口

基线为 `9d3f4f5`（v0.99.0）。按 R3 核对资产账本凭据、账户权限、执行服务到行情服务的本机 IPC、现货与永续市场准入、后台飞书和页面入口。回滚前先在费率设置中取消 OKX 独立费率，再取消勾选 OKX 并保存。此次没有数据库结构变动。

## 独立审查与处置

两路独立核对行情与页面、凭据与后台，初审代码快照 `736eb7b6`，修正后的代码快照 `81f3076e`。

| 发现 | 修正与验证 |
| --- | --- |
| P1，额度或费用未知被显示成交易所停充，提现字段也阻止了现货报价 | 单独保留原始充提状态和现货充值资格。测试分别覆盖开放但到账条件不明、停充、提现费用与提现标签。 |
| P1，明确拒绝只读权限后，早于拒绝的缓存应答可能恢复同一凭据 | 共享授权代次记录最近拒绝时间。权限及币链回包均核对来源时间。目录、余额、持仓触发的拒绝和随后的恢复均经替身验证。 |
| P1，无正价差时撤销账户仍显示其轮次与进度 | 有榜和空榜均重查原始目录，撤权立即清空机会、最近采样与计数；跨进程测试覆盖两种情况。 |
| P2，同一批两个飞书写入之间可能有外部账本变更 | 每条过线机会入队前再核对目录。测试在第一条消息入队时断开，第二条留在队列外。 |
| P2，正常续期清空了未变币链的历史和优先复核候选 | 续期时逐路线核对身份和充值资格，买入价格按原报价时刻到期。测试包含同账户续期、单独提高最低充值数和换账户。 |

Codex Security MCP 对 Windows 链接工作树返回无法解析 HEAD。凭据审查者通过原生 Git 读取上述固定对象完成本地静态审查，未生成插件托管报告。

增量复核发现，目录续期取消在途采样时仍可能误删有效历史并计入失败（P1），最低充值额仅改变末尾零也会误撤现货（P2），新增经验编号与旧条目重复（P2）。最终快照 `5e340049` 隔离了旧任务写入，保留应重新采样的候选，按精确十进制比较充值额，并将经验编号改为 L209。独立复核确认三项均关闭。本次范围内未遗留 P0、P1 或 P2。

- Windows 原生运行 `pnpm check`、正式页面构建和产物加载。相关链上行情、后台、资产与缓存回归一组 182 项通过。资产只读连接和签名相关一组 36 项通过，前端表单与导航一组 16 项通过。
- 在途续期修正后再次通过类型检查和受影响的扫描、IPC、后台测试 17 项。定向测试覆盖相同条件续期及单独剔除现货，均保留合格历史并重新扫描被打断的候选。
