# Ondo 多市场观察、APR 与延迟审查

2026-11-18，R3。公开观察、奖励采样及页面属于 R2；实盘遥测接触已有的令牌排队、请求、回执解析和心跳链路。回退版本为 v0.62.1。观察临时名单与浏览器参考本金不写入旧版实盘配置。

初次独立审查范围为 `40ec043` 至固定树 `f7f0919f`。一条审查聚焦订单、心跳和遥测，一条聚焦收益模型、名单隔离、过期状态与实际页面。Codex Security 另对候选提交 `596d336` 静态核查。

托管安全报告完成并回读，30 个变更文件全部覆盖。没有可报告的安全漏洞。报告指出 REST 盘口的非正数量、重复价及乱序价位会影响 APR 的数据依据，按下面的输入验证修复。

| 发现 | 修改与验证 |
| --- | --- |
| P1，保护撤单 429 后退避重试，耗时只算最后一次请求 | 从同一订单首次保护撤单的单调时刻计时，跨明确拒绝的退避。断线或结果不明不拼接成功分位。测试覆盖首次撤单至最终确认 1,030 ms 的全程 |
| P1，页面从后台返回的首次读取期间把旧会话显示为正在观察 | 在首个新响应前标记陈旧并禁止依赖旧状态的启动；普通轮询继续显示最近有效结果 |
| P1，按需 REST 明细可把缺少源时间的快照标成当前盘口 | 分钟采集和按需明细共用源时间校验；失败保留上次价格与时间，页面标注原因 |
| P1，恰好 5/10 bps 可能被浮点误差计入前一档或误报深度不足 | 先按定点价格的整数比值判断覆盖与分桶，再转换展示。拒绝乱序、重复价和零量深度档 |
| P2，未收到应答的心跳在静默断开时没有失败记录，排除样本文案也可能误读为订单未确认 | 非主动断线计数未应答心跳；页面标为未计入耗时，不将失败或不完整样本列入 P50/P95 |

增量复核在旧树重现了 3 个边界：429 退避期间撤单原因变为 `rate_limited`、公开/登录超时早于通常的静默超时，以及数组包装的异常价格通过字符串隐式转换。最终修订在令牌冷却期间保留同一单原有的保护撤单计时，只统计真正发出的 ping，并在解析十进制之前验证价格和数量都是标量。

对固定树 `7f73c13d` 的独立增量复核确认三项均已关闭。复现同一订单 429 退避并以限流原因重试后，得到 3,200 ms 的完整样本。公开订阅和私有登录超时计入实际发出的待答 ping，主动关停不新增成功样本或失败数。未发现仍待处理的 P0、P1。

## 已验证

- Windows 原生定向测试 160 项通过，覆盖 20 市场观察、实盘限制和拒绝观察参数、费率与波动缺失、收益冻结、断线、队列和撤换计时、奖励样本边界及页面表单。前后端类型检查及生产构建通过。Linux 账户锁和文件符号链接由发布门禁的 Linux CI 验证。
- 1280/390 像素浏览器覆盖市场选择、查看明细不重启、修改本金后 APR 同比例变化、停机冻结、无样本、后台恢复、实盘遥测替身和零写请求。模拟 21 个奖励市场时不会静默截断，最多同时选 20 个。
- 公开数据端到端验收使用独立临时数据目录和 20 个真实奖励市场。约 10 分钟后所有市场均至少有一档净收益数值，120 条买卖侧观察行可读，WS RTT 有 59 个有效样本；停止后保留收益快照。委托数为零。
- 研究用同机原生 BBO 与完整深度的到达时差及外部源限制，见 [模块文档](../ondo.md#11-延迟与提前撤单的验证顺序)。实际部署服务器的私有订单延迟和真实奖励回款仍待操作者验证。
