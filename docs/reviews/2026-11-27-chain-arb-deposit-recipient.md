# Gate 与 OKX 实际充值地址的只读模拟

2026-11-27，基线 v0.101.1（`c689e163`）。R3，涉及已有账本连接、只读签名路径、目标地址、报价与通知的有效期和飞书待发送数据。变更前范围与回滚说明见[模块文档](../chain-arb.md)。回退前关闭后台扫描，再安装 v0.101.1。账本和扫描配置无需迁移。飞书发件箱增加可空字段，新机会的待发时间单独存放，旧版查询无法投递；旧数据库保留普通消息和发送历史。

## 固定差异审查

| 范围与快照 | 初审发现和处理 |
| --- | --- |
| Gate、OKX 账本与选中地址，`cc239d73` | P1，默认 OKX 持仓权限读取将 HTTP 401/403 或业务拒绝当成普通错误，可能让旧地址继续有效。已在已签名的 OKX 读操作共享拒权分类。实际临时账本路径分别覆盖 HTTP 403、200 及 400 携带 50120，确认撤销目录和地址。 |
| 公共行情、执行服务内的链模拟、排行与页面，`4380a686` | P1，单币复核误用了扫描缓存的 Gate 交易规则；已把手动/扫描参数带到行情读取。P1，两条路线错误共享最早盘口时间，浏览器离线后也可能过长地显示历史；现分别计算每条路线的行情截止与账户证明截止。P2，公开买一不足以覆盖整笔成本的正常筛除被计入失败；已修正统计。 |
| 飞书真实出站路径与数据库，`86004279` | P1，旧版可能在回退后发送仍处于退避期的新机会。新发件行使用旧版不会选取的待发时间，实际调度使用可空字段 `guarded_due_at`。新版本启动时清理旧版剩余的未发送套利提醒。以旧版实际查询验证刚入队、失败重试和重新启动。 |

修复后的固定对象 `6a8c3d14` 复核通过其余问题，并发现 OKX 的持仓周期另有两处会吞掉明确拒权。成交或资金费历史读取现在透传拒权，当前账本的同一凭据立即作废。HTTP 503、公开合约目录返回 403 或旧账户迟到响应保留当前账户的证据。该修复与测试单列为 `5d5fc7a6`。

对固定增量 `6a8c3d14..5d5fc7a6` 的独立复核未发现 P0/P1。唯一一项 P2 已补测：同一凭据先撤权、再取得新的有效充值地址证明，随后原持仓历史请求返回 403，新证明立即失效。该测试文件在 Windows 上 25 项全部通过。至此 P0/P1 为 0，发现的 P2 均已修复。

Codex Security 的差异接口未能解析此 Windows 链接工作树的 HEAD。独立审查使用本地不可变 Git 对象，覆盖执行服务、地址归属、账户撤权、盘口与金额、混合版本 IPC、飞书及浏览器路径。旧的行情 IPC 操作不再返回使用普通地址计算的候选。地址只进入临时内存及其所属链的固定 RPC，不出现在 Kyber 请求、公开行情 IPC、页面或通知中。

## 验证

Windows 原生前后端类型检查、正式前端构建通过。首轮相应账本、链模拟、排行和通知等回归 184 项通过，修正后增量测试 129 项通过，最终资产账本与持仓周期相关回归 120 项通过。通过真实本机行情 IPC、HTTP、临时 SQLite 和模拟机器人验证正常入口。前端在 1280 和 390 像素宽度覆盖不同交易所实收量、无地址证据、排名及单币复核。两个虚构地址在同块、同笔预算下分别到账 10,000 与 7,900 枚，测得的授权、兑换及转账 Gas 分别折合 0.6 和 0.9 USDT。亏损、低于门槛、撤权、换地址、超时与旧行情不会形成有效机会。未使用真实私有账户、广播交易或向真实飞书群投递。

Windows 扩展回归遇到目录 fsync 和临时数据库目录删除的 EPERM，相关飞书用例在 Windows 单独通过，Linux 语义由同提交的主线 CI 验收。
