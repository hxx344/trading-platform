## 凭据边界的变化（本次的主要风险）

- 私钥此前只经 root 的终端进密钥文件；现在经页面 → 控制服务 → 执行服务。控制服务只转发请求体，不落盘、不记录；执行服务的接口与报错不回显请求体。
- 私钥以明文存在数据目录（属主是服务账户，权限 600）。能读数据目录的人能拿到它；损失上限是热钱包里的 gas：合约 owner 是另填的收款地址，热钱包没有提币入口。
- 状态接口只给热钱包地址、收款地址与节点主机名；日志与通知里只有地址。`mev-contract.json` 只有三个地址。
- 页面经明文 http 且不是本机地址打开时有警告，不强制拦截。
