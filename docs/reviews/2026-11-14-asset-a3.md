## 审查结论

无 P0/P1/P2，7 条 P3。

已核实：密钥文件以 `O_EXCL|O_NOFOLLOW`、0600 临时文件 fsync 后 link 到位，并发创建读到同一把密钥，格式不对只报错不覆盖；解密失败统一报 `UNSEALED_FAILED`；各数据源报错都是自拟文字，传输错误、签名 URL 不进报错；Var 的 Python 子进程只从 stdin 拿令牌、环境只留 PATH、丢弃 stderr；账本接口去掉 Aster 钱包地址。导入时读取子进程的 stdout 直接接写入子进程的 stdin，root 助手不经手明文；写入端连接数据限 1 MB、连接名白名单、按连接接口规则逐条校验后重新加密，与账本同一事务替换，两个子进程 60 s 超时。同步的全部写入经 `lease.write`，租约丢失或重新导入时整次 409、不记成数据源失败；Aster 汇总在写入事务里按当前账号列表重建。页面同步与表单共用写入名额，`finally` 复位，连接面板卸载即丢弃填过的密钥。
