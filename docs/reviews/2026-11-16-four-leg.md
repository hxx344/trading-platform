# 原油与海力士四腿（O6，R3）审查记录

- 批次：v0.58.0，方案与实施见 [../oil.md](../oil.md) 第 11 节。
- 等级：R3（执行编排、同一事务取 4 个合约锁、联动停止、资金）。

## 影响面与回滚（动手前）

- 用户可见行为：原油页、海力士页下单多「四腿组合」：选两个交易所，每所同时交易两个合约且方向相反，同一合约两所方向相反；一次预览、一次确认，生成两个成组的同所两腿任务；任务列表成组显示整体状态。
- 做法：复用执行器既有的同所两腿（首腿、对冲、保护、分批、结算），不新写 N 腿状态机；与工作台“四腿并发发送、一腿失败暂停并撤全部挂单”的差异写在 oil.md 11.3。
- 涉及文件：见 oil.md 11.4。不改存储结构（新字段只在任务 JSON 里）、规则、盈亏、划转、ADL。
- 失败时：任一所预览失败整体拒绝；任一锁冲突整体不确认；一所偏离、失败、停止或转人工时另一所联动停止（只停首腿、撤首腿挂单、已成交首腿照常对冲）；两所结束后成交不等发飞书告警。
- 回滚：见 README 回退表 v0.58.0 一行与 oil.md 11.5——先把四腿任务处理到结束；旧版本按两个独立任务读取，不联动。

## 独立只读审查（第 3 轮，范围 `5f2d091..520a55d`，新开审查者）

结论：P0 为零，P1 一条。

| 级别 | 发现 | 处理 |
| --- | --- | --- |
| P1 | 可差量按“步长 × 批数”估算，市价 IOC 也拿到余量：1 桶分 5 批、每批只成交一半，两所差 0.5 桶既不联动也不告警 | 按 docs/code-review.md 第 3 轮仍有 P1 的规定重新对齐方案（主代理），不在原方案上打补丁：联动改按首腿偏离事件触发（IOC/原生追价某笔少成交 ≥ 一个步长当场联动；本地追价按设计跳过的零头逐批记 `leadSkipped`，提前放弃在完成时按“计划 − 已成交 − 已跳过 > 0”判偏离）；告警容差改为一个步长 + 两所实际跳过量，不乘批数。已修（b1a2bd8），删掉估算口径 |
| P2 | 追价每批可差量没用该批计划量封顶 | 随上一条删除估算口径消除 |
| P3 | 计划非有限正数时不联动 | 已修：按“无法比较”并告警 |

作者与对齐方案的出入（第 4 轮已核实合理）：偏离的任务自己也停发后续批次，被它停的另一所结束时不反向联动；拒单与未发出的首腿不算偏离，仍按原规则失败或结束后续批次。
