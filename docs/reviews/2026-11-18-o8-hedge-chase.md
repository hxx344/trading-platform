# 原油与海力士对冲腿本地追价（O8）

2026-11-18，R3。基线为 `v0.64.1`（`26bcaf2`），范围是 `26bcaf2` 到本记录所在提交：`src/contracts.ts`、`src/executor.ts`、`web/src/oil-form.ts`、`web/src/hynix-form.ts`、`web/src/OilPage.tsx`、`web/src/HynixPage.tsx`、`web/src/oil-types.ts`、`test/hedge-chase.test.ts`、`test/oil-form.test.ts`、`docs/oil.md`、`docs/hynix.md`。

## 变更前约定

- 用户要求“双腿都支持追价”：原来首腿可追价、对冲腿只能市价；本批让两腿组合的对冲腿在 Binance、OKX 上可选本地追价（只挂单跟随同侧最优价），超过对冲追价时限（默认 10 秒）剩余按市价补齐。四腿与自动规则不变。规格见 [oil.md](../oil.md) 第 13 节。
- 影响面：意图契约、执行器对冲状态机、两页表单。失效时最坏是对冲延迟（最多追价时限）或转人工；不改变首腿规则、不改存储结构。
- 回滚目标 `v0.64.1`：回退前确认没有未结束的对冲腿本地追价任务；已结束任务旧版本可读，不涉及配置与数据迁移（13.4）。

## 独立审查

首轮按后端（契约与执行器）、页面（表单与两页）分两路只读审查 `26bcaf2..8e6db68`；之后每轮新开审查者只看修复增量。

| 发现 | 处理 |
| --- | --- |
| P1，`guardHedge` 未放行本任务刚撤的对冲挂单：交易所快照滞后时 `external_orders` 直接转人工，未对冲缺口不按市价补齐（L054） | `08c8817` 与 `guardLead` 一样放行本任务委托；新用例在修复前失败、修复后通过。复核确认 `postedHedge` 判定与 `sendPrepared` 兜底下不会掩盖仍在挂的对冲单 |
| P2，开仓对冲挂单部分成交后剩余低于最小名义金额，改价撤单后直接转人工 | `08c8817` 剩余过小且应对冲量不增加时不改价，到时限撤单后按原“低于最小名义金额”转人工；13.3 登记为已知后果，补测试 |
| P2，对冲委托累计到 `chaseOrderLimit` 后市价补齐也发不出 | `08c8817` 对冲委托达到 `chaseOrderLimit − hedgeAttempts` 时结束追价；`4df764d` 曾把下限取 1，第三轮指出 `chaseOrderLimit` 为 1 时唯一名额被挂单占掉，第四批改回不设下限（名额不足时直接市价），文档写明 |

| 发现 | 处理 |
| --- | --- |
