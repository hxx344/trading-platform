# 行情监控 M-3b（从工作台导入告警档位与机器人）审查记录

- 日期：2026-11-14
- 范围：设计见 [docs/monitor.md](../monitor.md)「M-3b」与 [docs/module-import.md](../module-import.md) §3、§4。
  - `src/monitor/alert-import.ts`：工作台 `oil/monitor.json`、`hynix/alerts.json`、`notifications.json` 的换算。
  - `src/service/import-monitor-alerts.ts`：以 Monitor 目录属主读文件（不跟随链接、每个文件至多 1 MiB），规划档位与 `feishuMonitor`。
  - `src/monitor/import-writer.ts`、`src/monitor/store.ts`、`src/monitor/alerts.ts`：以数据目录属主写待应用键 `alerts.<market>.import`，告警服务在启动和每轮巡检开头一次事务换上。
  - `src/service/config.ts`、`src/service/feishu.ts`、`src/service/main.ts`：新密钥 `feishuMonitor`、独立出站队列 `notify-monitor.sqlite`、`marketAlertHooks` 按机器人路由。
  - `src/service/import-channel.ts`、`src/service/import-helper.ts`、`src/service/import-workbench.ts`、`deploy/install.sh`：页面请求 `monitorAlerts`、助手与 CLI `--monitor-alerts`。
  - 页面：`web/src/ImportPanel.tsx`、`web/src/import-form.ts`、`web/src/MonitorAlerts.tsx`、`web/src/monitor-alerts.ts`。
- 等级：R3。改动涉及凭据（机器人地址与签名密钥）、以 root 运行的导入助手、对外发消息的路由。每轮新开独立只读审查代理。
- 影响面：
  - 只在用户勾选「同时导入告警档位与机器人」或 CLI 加 `--monitor-alerts` 时才读写；不勾选时导入流程与 v0.29.2 相同。
  - 只换档位不换机器人时不重启服务，10 秒内生效；机器人变化时写 secrets.json 并重启。
  - 没有 `feishuMonitor` 时，告警照旧发 `feishu` 和 notify.sqlite。
- 回滚：先从 secrets.json 删掉 `feishuMonitor`（v0.29.x 的密钥白名单不含这个键，会拒绝启动），再执行 `sudo bash install.sh --version v0.29.2`。
  - 已换上的档位留在 `alerts.oil` / `alerts.hynix`，旧版本照常读取。
  - 未应用的 `alerts.<market>.import` 键旧版本不读，无害。
  - 旧版不认识发送记录里的 `robot` 字段，发往 `feishuMonitor` 的记录送达状态可能显示不对，只影响显示。
  - `notify-monitor.sqlite` 里未发出的消息不再发送。
