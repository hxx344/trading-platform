# 金油双腿交易

2026-11-20 用户要求：交易中心加上金油交易，即黄金 `XAUUSDT` 对原油 `CLUSDT` / `BZUSDT` 的比值交易。定级 R3（下单、执行状态机、任务品种判断）。G1 随 v0.74.0 发布。行情监控里的金油比由另一批改动负责，见 [monitor.md](monitor.md)。

## 0 R3 四件事

- **用户可见行为**：
  - 左侧栏「交易中心」组在海力士之后多一个「金油」页（`#/goldoil`）。页面有金油比与盘口、金油持仓（XAU / CL / BZ），以及执行面板（任务、预览确认、下单表单）。
  - 同所下单是 XAU 对 CL 或 BZ 两腿等金额；跨所只做 XAU 同一合约两腿。
  - 飞书任务消息按金油写，包括各腿数量、均价与成交比值。
  - 原油页只列原油任务，金油任务不再出现在原油页。
- **影响面**：
  - `src/contracts.ts`：意图解析认 `market: 'goldoil'`；`XAUUSDT` 并入三所的可执行与可读合约。
  - `src/executor.ts`：任务品种改为按全部腿判断，涉及分批、结算、任务视图与 `recentJobs` 过滤。
  - `src/service/oil.ts`：多一份金油行情、两个只读循环和两个接口。
  - 飞书文案与页面。
  - 原油、海力士任务的解析、预览、结算与列表结果保持不变（由已有测试覆盖）。
  - 库结构不变，配置不变，不新增配置项。
- **失败与回滚**：
  - 金油盘口或持仓读取失败只记日志并在页面标出，不影响原油、海力士的循环与就绪判定。
  - 回退：`sudo bash install.sh --version v0.73.0`。回退前须在页面确认没有未结束的金油任务。旧版本不认识 `XAUUSDT`，无法推进或核对这些任务；重启时会把它们当原油任务处理，按桶结算会转人工。
  - 旧版本列表按首腿合约过滤：首腿为 CL / BZ 的金油任务会出现在原油页，首腿为 XAU 的不显示。库与配置都无需改。
- **本次不做**（写进第 7 节）：
  - 自动开平仓规则。
  - 两腿名义平衡与单腿调平。
  - 四腿。
  - 盈亏与资金费账本，包括 Bybit `BASE_COINS`。
  - 原油页持仓与盈亏里拆出金油的油腿。
  - 行情监控的金油比。

## 2 业务规则

- **启用**：不加新配置。配置了 `oil` 执行账户的服务同时提供金油交易，与原油、海力士共用以下资源：
  - 执行账户、密钥、启动检查与进程锁；
  - 同一个执行器与同一套合约锁（`账户:合约`）。
- **金油比口径**：比值 = XAU 价格 ÷ 油价，两者都按每单位 USDT 报价，比值没有单位。
  - 中间价比值 = XAU 中间价 ÷ 油中间价。
  - 可成交比值：卖出 = XAU 买一 ÷ 油卖一（空 XAU、多油，即做空金油比）；买入 = XAU 卖一 ÷ 油买一（多 XAU、空油，即做多金油比）。
  - 每所每个油品一行，即每所两行：XAU 对 CL、XAU 对 BZ。
  - 跨所为 XAU 同一合约两所买卖一之差（USDT），收在折叠区。
- **方向**：做多金油比 = 多 XAU、空油；做空金油比 = 空 XAU、多油。
- **意图**（`POST /api/preview`）：`market: 'goldoil'`，其余结构同海力士。
  - 同所两腿须一腿 `XAUUSDT`、一腿 `CLUSDT` 或 `BZUSDT`，任一腿在前都可以。两腿都是油、都是 XAU 或同一合约时，拒绝 `same_symbol`。
  - 跨所写顶层 `symbol`，只能是 `XAUUSDT`；油合约跨所请用原油市场。
  - 每腿填 `notional`（USDT 名义金额）或 `quantity`（原生数量）其一，两腿须同一种。规则与海力士相同：
    - `notional` 两腿须相等。预览按盘口中间价折算各腿数量，向下取整到步长；不足最小数量时拒绝 `notional_too_small`。
    - `quantity` 只用于平仓；开仓按数量拒绝 `open_requires_notional`。
    - 不接受 `barrels`。
  - 原油、海力士意图仍只认本品种合约，带 `XAUUSDT` 时拒绝。四腿与单腿调平拒绝金油。
- **分批**：与海力士相同，首腿按数量步长均分，对冲腿每批按两腿计划比例（`planHynixBatches`）。某批对冲腿按比例取整为 0（低于最小数量）时预览拒绝 `batch_size`。
- **结算**：两腿名义相近但数量不等，按计划比例结算，与海力士相同（[hynix.md](hynix.md) 第 2 节）。
  - 油腿在前、XAU 对冲时，XAU 按比例向下取整，最多留一个 XAU 步长的未对冲量：Bybit 0.01 XAU 约 26 USDT，Binance 0.001 XAU 约 2.6 USDT（按 2650 USDT 计）。页面在油腿作首腿时提示，建议 XAU 作首腿。
- **品种判断**：任务的品种按全部腿判断，不看首腿；库结构不变。
  - 任一腿为 `XAUUSDT` 的任务是金油任务；
  - 否则任一腿为海力士合约的是海力士任务；
  - 其余是原油任务。
  - 原因：金油任务的首腿可以是 `CLUSDT`。原来按首腿判断的地方会把它当原油任务，按桶结算转人工、列进原油页。这些调用点见第 3 节。
- **与原油共用 CL / BZ**（本批只写清，不拆分）：
  - 合约锁按 `账户:合约`。同一账户上未结束的金油任务与原油任务互相占用 CL / BZ 的锁，后来的预览会拒绝。
  - 交易所持仓按 `账户 + 合约` 合计。原油页持仓表的 CL / BZ 数量包含金油油腿。
  - 原油平仓的 `implicit_reduce`、原油自动规则的持有核对，看到的都是合计持仓。
  - 原油自动规则开仓时，单向账户上同合约有金油的反向油仓会被 `implicit_reduce` 拒绝：规则等 60 秒再判断，不计失败、不停用，事件写「同合约有其他仓位（可能是金油任务）」（海力士规则写「同合约有其他仓位」）。连续受阻满 30 分钟（`BLOCKED_NOTIFY_MS`）生成一条通知交给通知队列（未配置飞书机器人时只写日志），页面规则状态显示「被同合约反向仓位阻塞」；受阻间隔超过 120 秒算新的一次，预览通过即恢复并只记一条恢复事件（[oil.md](oil.md) 规则一节）。
  - 原油页持仓表与盈亏卡注明「CL / BZ 为账户合计，含金油任务的油腿」。
  - 金油页「按当前持仓填入」取账户持仓与金油任务累计净持有的较小值。累计净持有由 `/api/goldoil/state` 的 `goldoilHeld` 给出：对全部金油任务（不限最近 20 条）按创建顺序逐个任务把开仓成交加上、平仓成交减去，每个任务之后最小为 0（超量平仓不会抵掉之后的开仓）。部分成交、转人工的任务按实际成交计。两者不同时提示「账户另有 X 不属于金油任务，未填入」；XAU 腿同样处理。
  - 执行器自己核实不了成交的任务（已结束但委托仍为结果未知，或追价策略被人工强制释放）不静默计入：`goldoilHeld` 在该账户、方向的 `uncertain` 里列出合约，页面不自动填该腿，提示「有金油任务成交未核实，请按交易所持仓手动填写」；两腿都未核实时不填。该腿的 `long` / `short` 数值仍含执行器已知的成交（只读接口与 MCP 可见），只是不可信。`uncertain` 不会自动清除：任务已结束，执行器不会再核对这笔委托，此后每次都须按交易所持仓手动填写该腿。
  - 页面激活时每 2 秒读一次。每个任务的贡献按任务与其委托的 `version` 缓存，只有版本变了才重读；只对新插入的任务行查是否含 XAU 腿。
  - 在同一账户同时做原油价差与金油时，平仓前须先核对各自的持有量。拆分放到后续批次（第 7 节）。
- 其余规则与原油、海力士相同，包括价格保护、首腿市价 / Bybit 追价 / Binance 与 OKX 本地追价、对冲腿市价或本地追价、外部挂单拒绝与接管。

## 3 架构

- **`src/contracts.ts`**：
  - 加 `GOLD_SYMBOL`、`GOLDOIL_SYMBOLS`；`Market` 加 `'goldoil'`（名称「金油」），`XAUUSDT` 并入三所的可执行与可读合约。
  - `marketOfSymbols(symbols)` 按全部腿判断品种，替代原来只看一个合约的 `marketOfSymbol`（已删除，避免再按首腿判断）。
  - `parsePairIntent` 认 `goldoil`：按金额下单的规则同海力士，同所两腿须一金一油，跨所 `symbol` 只能是 XAU。
- **`src/executor.ts`**，品种判断的调用点：
  - `marketOfJob` 改用全部腿；
  - `planBatches`：凡不是原油都走按比例分批；
  - `planPair`：只有原油做等桶核对，预览不带 `barrels`；
  - `settleJob`：不是原油都按比例结算；
  - 成交明细里的数量单位，以及任务视图的 `market`。
  - `recentJobs(limit, market)` 的过滤：
    - `goldoil`：任一腿为 `XAUUSDT`；
    - `oil`：首腿属原油且没有 XAU 腿；
    - `hynix`：不变。
- **`src/service/oil.ts`**：
  - 遗留任务提示按全部腿判断品种。
  - `prepareOil` 多一份金油行情。
  - `goldoilViews` 给出 `GET /api/goldoil/market` 与 `GET /api/goldoil/state`。两个接口须登录，未配置 `oil` 时 404；只读令牌放行范围同海力士。
  - `oilLoops` 多「金油盘口读取」（3 秒）与「金油持仓读取」（15 秒）两个循环，失败只记日志，不触发任何规则。
- **`src/goldoil/market.ts`**：
  - 用 `createMarketReader` 读三个合约，按第 2 节给出金油比。跨所只列 XAU。
  - 金油行情自己读一份 CL / BZ 盘口，与原油行情各读各的（REST 时每所每轮多两次公开读取；有推送盘口时取推送）。
- **`src/live/instrument-ids.ts`**：OKX `XAUUSDT` ↔ `XAU-USDT-SWAP`。
- **模拟交易所**：上架 XAUUSDT（Binance 步长 0.001，Bybit 步长 0.01）。
- **飞书**：`describeGoldOilJob` 写方向（做多 / 做空金油比）、各腿计划与成交数量、均价和成交比值（XAU 均价 ÷ 油均价）；跨所写价差。
- **页面**：`#/goldoil`（`web/src/GoldOilPage.tsx`），左侧栏「交易中心」组海力士之后。入口与海力士一样，沿用原油状态的探测。版式照海力士页，不新增样式。
  - 金油比表：每所每个油品一行，列为 XAU、油买一 / 卖一，金油比（中间价）、卖出比值（空 XAU · 多油）、买入比值（多 XAU · 空油）。跨所 XAU 价差收在折叠区。
  - 下单表单：同所金油比 / 跨所 XAU。同所选油品（CL / BZ）与首腿（XAU 先下 / 油先下）。开仓只按每腿等金额，平仓默认按数量，可「按当前持仓填入」。改动交易所、合约、方向或动作时两腿数量清空。执行参数里可设分批。
  - 表单到意图的换算放在不依赖 DOM 的 `web/src/goldoil-form.ts`。
  - 任务卡片、持仓表、同步行等部件从 `OilPage.tsx` 复用；任务卡按 `market` 显示合约数量（金油、海力士）或桶数（原油）。

## 4 切换与回退

- 回退：`sudo bash install.sh --version v0.73.0`，注意事项见第 0 节。库结构未变，配置无需改。

## 7 本次不做（后置）

- **自动开平仓规则**：按金油比阈值开平。规则引擎目前只认原油、海力士。
- **两腿名义平衡与单腿调平**：同 [hynix.md](hynix.md) 第 7 节的金油版本。
- **四腿**：两所各一组金油比反向。
- **盈亏与资金费账本**：包括 Bybit `BASE_COINS` 加 XAU。
- **原油页拆出金油油腿**：原油页持仓与盈亏把金油任务的 CL / BZ 拆出；原油自动规则的持有核对区分金油油腿。
- **行情监控里的金油比**：另一批改动，见 [monitor.md](monitor.md)。
- **任务列表查询的性能**：`recentJobs` 用 `json_each` 扫描 `jobs` 表找 XAU 腿，任务多时变慢；金油累计净持有已改为只扫新行、按版本缓存，但每次仍按缓存的任务编号读一次版本。后续可加品种列或索引（涉及库结构，R3），本批不改。
