# 平台首页加载与导航读取

2026-11-20，基线为 v0.72.1（`443d8c1`）。按 R2 审查，范围为两个 HTTP 页面入口、静态资源、导航摘要、页面分块及行情展示缓存。可用 `sudo bash install.sh --version v0.72.1` 回退，配置和数据库都可沿用。

## 独立审查

首轮核对从基线到源码树 `50d32d0` 的差异，后续分别复核 `329ec84`、`6b49f2c`、`d619fc0`、`3a35006` 的增量。静态文件与导航摘要均经过现有会话检查。摘要只返回模块可用性、行情开关和代次以及外壳连接信息，未加入只读令牌的允许路径。Codex Security 的差异扫描未能识别 Windows 工作树，此项由独立源码审查和 HTTP 权限测试核对。

| 级别 | 触发条件 | 处理 |
| --- | --- | --- |
| P1 | 一个市场的写入应答晚于新修订，或另一市场在完整读取期间改变开关 | 仅采纳已配置市场当前或更新的修订，重新读取完整状态和摘要，取消旧请求 |
| P1 | 切回原油时完整状态已看到采集器重启，摘要仍停在旧代次 | 清除变更市场的缓存，摘要和完整状态的开关、代次都一致后才挂载该市场 |
| P2 | 海力士的修订触发完整状态重读，导致原油告警表单被卸载 | 重读期间保留未变市场的元数据与表单。浏览器验证未保存的阈值和展开状态都保留 |
| P2 | 直接打开设置会遗漏来自原油页的字段网格样式 | 共享布局移到入口样式，两种宽度分别为四列和两列 |
| P2 | CrossEx、Ondo 的页面文档还描述旧的模块探测 | 入口说明改为读取导航摘要 |
| P2 | 仅启用原油的配置换为仅启用海力士，两份读取暂时没有共同市场，快讯页签也可能遮住失败原因 | 原市场显示核对状态和重试按钮，已选中的异动行情仍可查看。没有可显示的市场或快讯时才显示空状态 |

最终增量独立复核覆盖 11 组状态组合，以上问题均已关闭。

## 验证

Windows 原生执行了 `pnpm check`、`pnpm build:web`。HTTP、控制进程切版、只读令牌、行情开关、展示缓存与样式的 8 个定向测试文件共 55 项，53 项在 Windows 通过。普通文件符号链接受本机权限限制，POSIX 文件权限 0600 无法在 Windows 验证，这两项由正式发布的 Ubuntu CI 执行。

Chrome 加载生产构建，通过本机 HTTP 服务和模拟账户读取。13 个页面分别在 1280 和 390 像素下直接打开并对照上版，核对主区域、共享字段网格、页面样式、横向溢出和 CSP。另核对跨页导航、丢失分块后切页与刷新、会话失效后恢复、快讯页的轮询、迟到的开关写入和跨市场编辑。热切回原油时，完整读取先看到新代次的情形下，页面等摘要核对后重新取价，未显示上代价格。

后续增量单独核对了市场列表整体替换。摘要先变且完整读取返回 503 时，页面提供重试，点击后正常展示海力士。完整读取先变时，页面等待摘要后展示原油。两份列表都为空且未开启快讯时，页面显示未启用。开启快讯后重测，原市场仍可重试，已选中的异动行情保留筛选输入。

首页在 5 Mbps、80 ms 延迟、空业务数据下各冷开三次，首次内容绘制中位数从 3.000 秒降到 0.412 秒，配对组出现时间从 3.093 秒降到 0.517 秒。首屏 JS 和 CSS 响应正文从 1,707,647 字节降到 103,654 字节，首轮不同 API 从 10 个降到 4 个。同一浏览器暖开时静态资源传输量为零。生产账户、交易所接口和用户服务器未参与这组测量。
