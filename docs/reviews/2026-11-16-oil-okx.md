## 影响面与回滚（动手前）

- 用户可见行为：原油、海力士页可选 OKX：OKX 同所两腿，以及与 Binance / Bybit 的跨所两腿；OKX 首腿可用市价或本地追价；规则可选 OKX；原油盈亏计入 OKX 腿；设置页「从工作台导入」与 `install.sh --import-workbench --oil` 可导入 OKX 执行账户。
- 涉及文件：`src/live/okx.ts`（新）、`src/live/permissions.ts`、`src/live/setup.ts`、`src/live/values.ts`；`src/contracts.ts`；`src/service/config.ts`、`oil-config.ts`、`import-workbench.ts`、`main.ts`、`oil.ts`；`src/oil/market.ts`、`src/hynix/market.ts`（跨所价差改为交易所两两列出）；页面 `web/src/OilPage.tsx`、`HynixPage.tsx`、`oil-form.ts`、`hynix-form.ts` 等；`deploy/install.sh`（只改注释）、`deploy/test-install.sh` 第 2 部分；测试与文档。
- 不碰：执行器状态机（OKX 走既有的 VenueConnector 接口）；Binance / Bybit 连接器；划转、ADL、资产、行情监控；鉴权边界。
- 失败时：启动检查（权限恰为读取与交易、绑定 IP、账户等级、持仓模式、UID）不通过就拒绝启动；写请求结果不明时按执行器既有的观察窗与核对收口，不重发同一委托。
- 回滚：见 README 回退表 v0.56.0 一行与 oil.md 10.5——先把 OKX 腿任务处理到结束、停用 OKX 规则、平掉 OKX 持仓（否则旧版本不再管理，跨所组合只剩单腿敞口），再从 `oil.accounts` 与密钥文件删掉 `okx`，然后 `sudo bash install.sh --version v0.55.0`。配置里还有 `okx` 时旧版本启动失败（已实测）。
