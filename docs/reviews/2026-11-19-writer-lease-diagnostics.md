# 执行器写入租约失效诊断

2026-11-19，实施起点 `5a53bd7`，发布基线 `901a7e2`（`v0.69.0`），风险等级 R3。改动位于执行器的唯一写者校验和异常停止通知。

## 实施范围与回滚

- 执行器首次判定失去写入权时，日志和飞书报告超时、其他实例接管、同一持有者代次变化或记录缺失，并列出上次成功续租、本实例到期时间与持有者变化情况。
- 诊断取自写入校验当次读取的记录。成功获租或续租后在内存保存时间，旧实例仍按现有条件永久停止写入。错误分类会影响故障判断，任何诊断都不能授权续租、恢复写入或覆盖新实例的记录。
- 回滚到 `v0.69.0` 即恢复原告警，无需处理数据或配置。本次范围限于租约诊断，历史故障的进程负载、主机调度及交易结果仍需各自的运行记录。
