## 第二轮（新审查代理，只看修复）

无 P0/P1/P2。5 个 P3 均已修复：

1. `writeBoth` 第二个临时文件失败时第一个（含私钥）留下 → 分两次登记，`finally` 必删。
2. 单独运行导入器时回滚改了密钥文件属主 → 改为硬链接保留旧 inode，失败时 rename 回去。
3. `set -e` 或 Ctrl-C 退出时不恢复 → EXIT trap 在非零退出时恢复。
4. 首次即用导入安装、启动失败后仍重启并保留开机自启 → 恢复后没有配置就停止并取消自启。
5. 备份清单与导入器判断密钥文件是否在本目录时规范化方式不同 → 两边都用 `path.resolve`；悬空符号链接按存在处理并拒绝。
