# 链上折价套利

## 首版范围

在「链上」工作区按指定币种和 USDT 预算比较两条路线。链上用 KyberSwap 的指定金额买入报价，首批覆盖 Ethereum、Arbitrum One 和 BNB Smart Chain。交易所先接 Gate 的 USDT 现货和 USDT 线性永续。币种由链和 ERC-20 合约地址确定，交易所代码仅用于查目录。沿用行情监控的配置、设置页导入和命令行启用入口，不新增账户、密钥、配置迁移或常驻采集。

- 现货路线按预计到账数量逐档吃买盘，核对所选链的币种身份、充值状态与交易状态。结果是当前盘口下的估算，到账前价格可能变化。
- 永续路线按可覆盖的数量比较链上买入均价和开空均价，列出开仓基差。基差收敛情景单独列示，手续费、链上开销、资金费与离场成本须有明确口径。
- 同名异币、报价过期、盘口不足、上游不可用时展示具体原因。页面按需订阅单个币，离开后停止刷新。服务端只请求固定公开行情接口。
- R2，只读测算。回退版本 v0.95.0。工作台 7745181 的 `modules/monitor/app/perpetual-panel.tsx` 和 `server/perpetual-spot-transfer.mjs` 提供行情与链身份显示参考。工作台没有对应的链上买入页面。沿用现有页面组件与样式，使用两张独立结果卡，在手机上按现货、永续顺序阅读。

## 使用与测算

通过设置页「从工作台导入」启用行情监控，或运行 `sudo bash install.sh --import-workbench --monitor`。已有合约价差监控的服务升级后可直接打开「链上 → 链上折价套利」。关闭合约价差监控后查询暂停。首版不存查询历史。

填写链、ERC-20 合约地址、Gate 币种代码与买入预算。示例为 Arbitrum One 的 ARB。计价统一按 USDT，比价以链上的 USDT 和交易所 USDT 等值为前提。Ethereum 使用 USDT，Arbitrum One 使用 USDT0，BNB Smart Chain 使用 Binance-Peg USDT。买入均价为实际输入金额除以 KyberSwap 路由预计输出的代币数量；每次获取目标合约的 decimals，以链上最小单位换算。

Gate 先以代码查资产目录，再按链和地址核对身份。以公开买盘逐档计算足额卖出或开空的均价，展示可覆盖数量与剩余零头。现货须能按该网络充值；提现状态单列。代币转账税、到账数量、账户最低充值额与个人费率需要按交易所和代币实际规则核对。对不能按面额全额到账的代币，当前现货测算不适用。

现货预估差额按可卖数量分摊链上成本，然后扣卖出手续费及输入的路线其他成本（Gas、发送代币等）。永续按整张合约向下取整，开仓基差为开空均价除以链上买入均价减一。收敛情景假设对应数量的现货和永续按同一价格退出，按开仓名义金额估算两次永续手续费，再扣输入的其他成本（Gas、现货离场等）。资金费与未覆盖的尾差单独留给操作者评估。两条路线其他成本留空时，页面只显示毛差额。费率单位为 bp，1 bp = 0.01%。

安装版由行情进程访问固定的 KyberSwap 路由、链 RPC 的只读 eth_call 和 Gate 的公开目录、盘口，经本机 IPC 返回执行服务。页面每 10 秒查询；服务端按报价源时间和盘口最后变更时间检查，任一有效路线最早的数据满 15 秒后，该快照撤下。同一读者最多同时处理四个查询。没有私钥、签名、订单、提币指令或数据库迁移。

代币数量从最小单位开始计算，到每条路线按交易步长向下取整后再格式化。现货卖单的最低价格按 Gate 买一价与允许滑点计算。永续空单还受实时标记价偏离限制，两条下限取较高者。任一市场在允许范围内的盘口不足时，该路线显示原因。[Gate 现货市价单示例](https://www.gate.com/announcements/article/48909) · [Gate 永续限价规则](https://www.gate.com/help/futures/futures-logic/22083/contract-order-price-limit)

公开接口参考：[KyberSwap EVM 报价](https://docs.kyberswap.com/developer-guide/aggregator-api/aggregator-api-specification/evm-swaps)、[Gate 现货](https://www.gate.com/docs/developers/apiv4/en/spot/)、[Gate 永续](https://www.gate.com/docs/developers/apiv4/en/futures/)。

## 自动扫描（v0.97.0）

自动扫描按 Gate 目录取得 Ethereum、Arbitrum One 和 BNB Smart Chain 的代币地址，在「链上折价套利」页按买入预算持续分批询价。每个候选复用单币入口的链上报价、Gate 身份、充提和盘口判定。按路线的扣费价差从高到低排列，现货和永续分别标识。在榜单上打开单币复核时，沿用金额和费率并重新取得报价。

扫描的建仓 Gas 采用 KyberSwap 对本次路由的报价估算，以输入 USDT 对应的美元估值换回 USDT。缺失此估算时该币不进入扣费榜。额外转账、退出等费用由操作者按路线设置，永续按基差收敛情景和两次合约费测算。排名分母为可成交数量对应的链上买入成本。页面会区分仍有效的机会、已过期的采样记录、无法测算和扫描进度。

本批为 R2。沿用原行情监控开关、设置导入和 IPC 拓扑，扫描进度保存在行情进程内存。页面有可见订阅时按需推进，离开后本批收尾。回退到 v0.96.0 无需配置或数据迁移。

每次最多查两个币链组合，各参数组共用启动间隔和并发上限；每份参数一轮覆盖所选网络的全部候选，部分名额用于复核此前发现的正价差。相同参数共用进度，行情开关代次变更后重新开始。目录由 Gate 币种、USDT 现货交易对和 USDT 永续 ticker 并集构成，每五分钟刷新。无现货交易或充值关闭时，仍可发现有同币永续的候选。多代码指向同链同地址、网络记录重复或合约地址缺失时跳过。

榜单只收录至少一条路线可测算、按该路线覆盖数量扣费后价差仍为正的记录。按量 DEX 路由已包含池内成交影响，再减去估算的买入 Gas、一次现货卖出费或两次永续交易费，以及手填的该路线额外成本。后者默认 0，转账 Gas、现货退出费用等可按需填写，资金费不计。每个报价最多有效 15 秒；过期发现移到「最近采样」，五分钟后移除。重新核验时变为负或无法测算的记录撤下。暂停后可查看此前采样；机会复核使用新盘口。

同一币种的两条路线独立到期，以各自 Gate 买盘和链上报价中较早的时间为准。目录支持中文币种代码。目录更新发现充值关闭或市场撤下时，所有扫描条件下对应的路线都会撤下，其余合资格路线继续报价。

从榜单打开单币复核后，每次刷新都会重新读取该币的充值、交易状态，并核对有效的市场目录。目录到期会重新获取；读取失败时页面显示原因。手动改选币种、网络或合约地址后，使用新身份单独查询。

## 后台扫描与交易所（v0.98.0）

用户在现有页面保存扫描预算、网络、交易所、费用和飞书阈值。行情监控服务按保存的设置自行运行，页面关闭与服务重启后继续工作。使用原有监控总开关、状态库及通知发件箱。按币种、链、地址、交易所与路线区分机会，只对新鲜且扣费价差严格高于阈值的结果提醒，正文标明净收益的币种及永续收敛假设。

本批优先接入 Binance，并接入 Bitget。Binance 官网钱包状态页的公开目录给出网络地址、充提及代币面额，Bitget 公共市场目录给出合约地址与充值条件。无法取得可靠身份、面额或盘口的路线不估算。交易所的公开行情留在行情层，飞书继续经现有通知服务发送。R2，只读市场数据、调度与提醒，无凭据或数据库结构变更。工作台没有对应的后台配置页，本版沿用现有价差扫描页和行情监控的启停交互。回滚到 v0.97.0 可继续按页扫描，无需迁移数据库。

首次升级后后台扫描默认关闭。在页面勾选交易所并保存启动，可按场所覆盖公用的现货和永续费率。阈值单位为 bp，100 bp 等于 1%；恰好等于阈值不通知。沿用行情飞书机器人，未单独配置时使用平台告警机器人；未配置机器人时仍可查看榜单。同一交易所、网络、代币地址和路线的飞书消息每 30 分钟最多入队一次，重启保留限频。切换合约价差监控总开关会暂停或恢复后台。扫描设置写入已有的 `monitor.sqlite`，每次服务重启从新行情开始。

币安现货盘口的 REST 快照没有成交簿更新时间，复核时结合对应交易对的公开深度推送和更新序号确认新鲜度。官网钱包网络目录的字段缺失、面额与链上代币不符时跳过，其他交易所独立运行。Bitget 使用普通 USDT 现货及 USDT 线性永续，按对应盘口、交易步长、买盘保护和最低充值量核验。[币安钱包网络状态](https://www.binance.com/en/network) · [币安现货深度推送](https://developers.binance.com/docs/binance-spot-api-docs/web-socket-streams#diff-depth-stream) · [Bitget 市场数据](https://www.bitget.com/docs/catalog/market/market-data)
