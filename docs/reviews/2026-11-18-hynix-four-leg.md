# 海力士调平与四腿成交边界

2026-11-18 至 19 日，R3。基线为 `v0.64.0`（`e77f258`），范围是 #55、#59 和 #60。

## 变更前约定

- 海力士规则在执行账户仍持有仓位，或该账户的规则任务尚待核对时，手动加仓、减仓调平均应给出冲突原因。执行器在预览和确认时读取规则库的持仓及在途记录。停用规则仍保留其仓位归属。规则库不可用时，调平应拒绝。
- 四腿本地追价首腿已结清后，按该批实际成交与原有最小下单规则记下不可发送的零头，覆盖对冲尚在途、截止和重启。真正少成交或提前放弃仍按既有规则联动。验证单笔首腿的一个步长、最终两所成交的严格容差、海力士对冲换算与累计成交回报。
- 交易写入改动位于执行面，沿用执行器写入租约、合约锁和原有存储结构。四腿最终成交比较由执行器和页面共用。失效可能导致规则无法按原数量平仓，或四腿任务误停另一所的首腿。验收使用模拟交易所与临时数据库。
- 回滚目标为 `v0.64.0`。回退前结束或核对本次涉及的在途任务，回退后在规则持有期间避免手动调平。已有仓位差异需按实际成交核对，本批只保护后续操作。

## 独立审查
