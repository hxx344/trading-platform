# 价差与业务记录的缓存复用

本批从 v0.70.1（`4808e67`）开始。监控页面打开或切换时复用已有的展示行情。入场、出场、调仓和关联持仓，以及账本、盈亏、资金费和分页历史，在平台核对当前会话、账户和可见范围后复用相同数据。执行时的盘口、预览确认、在途委托和状态核实继续各自实时读取。

公开展示与传输按 R2 验证。涉及账户读取、权限和私有数据库的部分按 R3 验证。误用过期或跨账户数据会导致成交方向、持仓证据和页面统计错误。服务端以当前可见结果为准，私有响应只在当前页面会话内保留用于协商的副本。本批合入 v0.70.2（`5acb6c8`）后发布，回退可用原数据目录执行 `sudo bash install.sh --version v0.70.2`。本次不改变交易写入和下单时的核验规则。

验收覆盖同一数据重复打开、时刻更新但记录不变、新增和修订一笔、分页和窗口变化、切换账户或连接、明确拒绝访问、迟到应答、过期显示及旧客户端兼容。使用替身和隔离的本地数据库验证，不访问真实账户。

## 页面与接口

持仓、套利成交、资产历史与现金流、油品盈亏、期权收益、配对余额与划转记录、ADL 事件、日志、奖励统计和合约目录按具体查询保存已读版本。行情监控的报价、已结算资金费、市场指标和质量数据使用同一协议。合约深度、退出估算、下单预览与在途订单通过原接口读取。

每次协商都先走对应接口的登录、权限、模块开关及数据读取。相同结果返回 204，有变化时复用上一份中的相同片段，包含当前的顺序、删除、修订和观测时间。只读令牌使用原有打码和大小限制。页面在内存中保存最多 64 份且合计不超过 4194304 个 UTF-16 代码单元的序列化结果。重新登录、变更连接或导入会使对应缓存失效。普通账本同步可沿用上次版本。旧客户端、版本丢失、结果过大或差异不划算时发送完整结果。

页面以 SHA-256 摘要校验收到或还原的正文，校验失败在原请求时限内完整补读一次。局域网普通 HTTP 与 HTTPS 执行相同的校验。服务端在异步行情读完后再次比对开关修订号。
