# 期权 Greeks G2a（周五定时开仓、IOC 兜底）审查记录

- 日期：2026-11-13
- 范围：见 [docs/options.md](../options.md) G2a。`src/options/engine.ts`（定时开仓 tick、窗口与 ISO 周、每周一次、错过提醒、页面开关、IOC 兜底）、`src/options/orders.ts`（`iocOrder`）、`src/options/client.ts`；服务 `options` 新配置字段、`POST /api/options/auto-open`、工作台导入开仓时间与 `ALLOW_MARKET_FALLBACK`；期权页定时开仓一行、确认框、IOC / BBO 标记。
- 等级：R3（无人值守的实盘开仓、对手价补单）。两路独立审查（A：引擎与 IOC；B：配置、导入、接口与页面）+ 修复复审。

- 实盘：本版本未在真实 Bybit 期权账户上运行定时开仓或 IOC 兜底。定时开仓默认关闭（配置缺省、导入也不打开），IOC 兜底默认关闭。
