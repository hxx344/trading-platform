# 期权 Greeks G1（执行引擎、服务接线、期权页、工作台账户导入）审查记录

- 日期：2026-11-13
- 范围：见 [docs/options.md](../options.md) G1a/G1b。`src/options/`（客户端、期权链、选腿与风险、跟价下单与核对、任务与对账、跟踪策略、状态库）；服务 `options` 配置、`bybitOptions` 密钥、启动检查与进程锁、`/api/options/*`、飞书任务事件；期权页 `#/options`；`install.sh --import-workbench --options` 与页面导入。
- 等级：R3（实盘下单、凭据导入、唯一写者边界、新状态库）。两路独立审查（A：执行引擎与服务接线；B：工作台导入、安装与页面）+ 修复复审。
- 回滚：`sudo bash install.sh --version v0.10.1`。回退前在期权页确认没有进行中的期权任务和未结束订单，并从 `config.json` 删掉 `options`、从 `secrets.json` 删掉 `bybitOptions`（旧版本不认识这些字段）。`options.sqlite` 留在数据目录，旧版本不读；主库不迁移。
- 实盘：本版本未在真实 Bybit 期权账户上下过单；首次实盘（G1d，周五最小数量 0.01 开仓一次）由用户操作，且先在工作台关闭自动开仓并重启期权模块。

## 第一轮（两路独立审查）

无 P0。

| 级别 | 来源 | 问题 | 处理 |
| --- | --- | --- | --- |
| P1 | A | 下单应答丢失且实时 / 历史订单都查不到的订单永远是“未知”：拒绝一切计划（含平仓）、跟踪腿无法退役，也没有人工出口 | 已修：从未拿到订单号、发出已超过 2 分钟（Bybit 接收窗口 5 s）且该轮每次读取都明确查无此单（无读取失败）时按未下单结算（成交 0）；有订单号的仍保持未知。测试：请求没到交易所 → 对账结算 → 可再下计划 |
| P1 | A | 四腿同时挂单，卖腿先成交后风险 / 净价超限、行情过期、停止或超时会撤掉买翼，留下亏损无上限的裸卖（工作台同样如此） | 用户决定改为先买后卖：开仓买翼全部成交后才下卖腿，平仓先买回卖腿再卖买翼；买入腿未全部成交时卖腿不下单。测试：顺序、买翼部分成交时不下卖腿、停止与风险超限只撤买翼 |
| P1 | B | 导入只读环境文件的 `AUTO_OPEN`；工作台改了 `.env` 未重启模块时，运行中的进程仍会在周五自动开仓，形成双写者 | 已修：以 root 读 `/proc/<pid>/environ`，`app.main:app` 且 `STATE_FILE` 指向该状态文件的进程仍开着自动开仓即拒绝；读不到候选进程环境也拒绝。文档 §4 第 1 步改为改环境文件并重启模块 |
| P2 | B | 导入助手与命令行导入不带服务的代理设置，需代理的服务器上读 Bybit 账户必然失败 | 已修：导入 unit 加 `EnvironmentFile=-…/environment`；`install.sh` 命令行导入按同一文件传入环境 |
| P2 | B | 工作台改过的其余估算参数（`OPTION_*_FACTOR` 等）静默丢弃 | 已修：与本服务所用值不同的列在导入提示里；文档 §3 列明不导入的参数 |
| P2 | A | 配置了 `options` 后重启时 Bybit 不通 / 密钥权限被改，整个服务拒绝启动（ASTER 划转与 ADL 一并停） | 登记：与原油模块同一设计（启动检查失败即回退旧版本），未改 |
| P2 | A | 周日到期交割后 `get-closed-positions` 是否含交割记录、`side` 口径未经真实账户验证，可能导致跟踪腿不退役、下周开仓被挡 | 登记：已在 §6 待实测，G1d 前用真实账户核对 |
| P3 | A | 启动检查不比对配置的 `marginMode` 与账户实际模式 | 登记，未修 |
| P3 | A | 对账持锁期间新计划返回 `operation_active`，平仓历史回溯最长持锁 120 s | 登记，未修（只影响体验） |
| P3 | A | 测试缺口：10002 重发、白名单拒绝码、改单 110001 后撤单读到已成交 | 登记，未补 |
| P3 | B | `readPlain` 先 lstat 后读有时间差，可被换成符号链接或 FIFO | 已修：`O_NOFOLLOW` 加 `O_NONBLOCK` 打开，对描述符 fstat，限长读取 |
| P3 | B | `secrets.json` 有多余 `bybitOptions` 而配置无 `options` 时，`parseServiceSecrets` 先报未知键，`planOptions` 的专门提示走不到 | 登记，未修（同样拒绝导入，只是提示不同） |
| P3 | B | 提交结果未知后计划倒计时一到，确认按钮被禁用，但提示让用户再点确认核对 | 已修：结果未知时不因过期禁用，倒计时文案说明 |
| P3 | B | 订单编号前缀与工作台同为 `ic-`，回退后工作台可能把本服务成交认成自己的 | 已修：改为 `tpo-` |
| P3 | B | 文档 §4 “工作台期权页关闭自动开仓”与实际不符 | 已修 |
