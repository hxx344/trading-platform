# 链上折价套利的整笔成交与充值资格

2026-11-27。基线为 v0.101.0 的 `6be5f4f9`。R3，涉及资产账本 Gate 连接、公开行情到执行服务的准入、后台机会及飞书通知。实施前的范围与回滚条件见[模块说明](../chain-arb.md)。回退前先在扫描设置中关闭提醒，再安装 v0.101.0。无需迁移配置、数据库或密钥。

## 独立审查

行情与收益初审对象为 `2358b8fc`。Gate 账本与执行服务独立审查对象为 `b85feed0`。Codex Security 托管接口无法解析 Windows 链接工作树的 HEAD，凭据审查使用本地 Git 固定对象及离线正常入口，覆盖签名路径、应答脱敏、权限撤销和账户更换。

| 发现 | 修正与回归验证 |
| --- | --- |
| P1，Gate 公开元数据无法核实最低充值量 | 执行服务从已有账本连接读取该币充值费和账户支持的目标链，并以精确的原币转账实收量比较最低额。现货和永续均须通过。 |
| P2，合并行情时间会掩盖单条来自未来的路由 | 对整笔和 1% 预算的两个报价分别检查有效期。用两个方向的异常时间回归。 |
| P2，模块说明仍沿用旧版费率与路由条件 | 标注历史设计，按现行整笔预算、转账实收、两腿退出费用及充值准入重写使用说明。 |
| P1，Gate 单币成本留空时丢失毛差额，亏损值也无法显示 | 增加仅供手工参考的结果，保留毛差额或非正净差额，标明账户未核验。扫描及提醒只接受正净收益。 |
| P1，HTTP 200 内的 Gate 明确拒权错误未使其他币的充值证据失效 | 余额、充值费与充值地址读取共用已知拒权错误识别，对同一凭据撤销资格。覆盖 HTTP 拒绝、业务拒绝及晚到应答。 |

固定快照 `ce2c99ef` 的独立复核以真实资产连接入口确认，试连时用相同的已存凭据收到明确拒绝，也必须撤销该修订的证明。不同凭据试连失败则保留当前账户的证明。复核快照 `98f009a4` 时另发现同一账户在试连过程中先拒权再恢复的情形。修复后按数据库、密文修订、导入批次和密钥文件识别账户，在试连拒权送达时作废该连接当时有效的证明；换账户不受影响。

最终固定增量 `98f009a4..d2e21377` 已经独立复核。再次拒权、恢复、外部换账户与三条链的余额位置对照均通过，范围内无遗留 P0、P1 或 P2。

## 验证与限制

- Windows 原生 `pnpm check` 通过。行情、账本与前端的相关测试合计 163 项通过。正式前端构建和 Chrome 在 1280、390 像素宽度下通过验收，覆盖 Gate、OKX、缺少连接、毛值和负值的手工参考提示，以及旧版应答被拦截。
- Windows 原生测试覆盖链与完整合约地址、同名异币、停充、买入及转账扣量、价格影响、现货及永续整手与深度、精确最低额、混合版本行情 IPC、飞书阈值与账户撤销。HTTP 和本机 IPC 接入生产处理流程，账本签名测试使用临时 SQLite 和虚构凭据，飞书使用替身发件箱。
- 公开 RPC 与 Kyber 路由实测。北京时间 11 月 27 日 04:32，用 1,000 USDT 对照同区块 10 USDT 的每 USDT 买入实收，CYBER 的 Ethereum 路线价格影响为 9.26%，BNB Smart Chain 为 49.29%，旧 Ethereum DYDX 为 10.64%。均超过 5% 上限。该数值随区块、流动性与预算变化。
- 出包前核对行情入口时发现，最初计算 ERC-20 余额存储位置的代码引用了开发依赖。现复用仓库自带的 Keccak-256 实现，三条链的存储位置分别对照 ethers 的测试结果。禁用第三方运行时依赖的 Node 装载检查通过。修复试连后相关账本与扫描测试 34 项通过；最终增量再跑类型检查、DEX 与 Gate 关联测试 33 项通过。
- 普通地址的模拟转账可测当前代币扣量。实际充值地址可能适用特别规则，未来到账价格、合约资金费与平仓盘口仍未知。未访问真实 Gate 或 OKX 私有账户，未向实际飞书群投递，未执行真实买入或充值。
