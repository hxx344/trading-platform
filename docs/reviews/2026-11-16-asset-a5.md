| 级别 | 发现 | 处理 |

| P2 | 只读校验拒绝分支只测了 Binance `enableFutures` | 已修：Binance 全部写权限字段、Bybit `readOnly`、OKX `perm` 与 config 条数各补拒绝组，并断言之后不发持仓请求 |
| P2 | 成交面板跟读只在 `data` 变化时重判，读取失败时一直每 5 秒请求，36 次上限失效 | 已修：抽成纯函数 `followUpStep`，仅成功且仍在读时跟读，失败或结束回例行周期；补测试 |

| P3 | `await Promise.resolve()` 后重查连接表的注释夸大了作用 | 已修：注释写明同步库下只覆盖微任务里排好的写入，换 Key 的安全性靠 revision 键与 refresh 前后的检查 |
