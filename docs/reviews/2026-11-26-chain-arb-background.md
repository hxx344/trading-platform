# 链上套利后台扫描与多交易所提醒

2026-11-26，基线 `7c8bb7f`（v0.97.0）。R2，涉及公开行情、扣费测算、后台调度、监控设置和通知。检查范围包括 `src/chain-arb`、行情 IPC、监控服务及 HTTP 入口、飞书发件箱、网页和对应测试。回退 v0.97.0 可继续使用按需单币及 Gate 扫描，不需要修改配置或数据库。

## 独立审查

后端初审树 `01795b05`，完整树 `c8a0708e`。两路分别核对调度、通知和行情适配，以及前端设置、排名、复核与交易所数据语义。

| 发现 | 处置 |
| --- | --- |
| P1，共用请求额度饱和时，按固定顺序排在第三位的场所会持续被误判为上游限流 | 共享额度按到达顺序分配，并保持同时查询数与每秒启动次数上限。使用前两所慢查询和第三所在途等待复现并验证。 |
| P1，单独勾选的交易所费率与公用值相等时，保存会清除覆盖，后续修改公用费率会改变原本固定的费率 | 保存显式选择的覆盖。以两次保存检验独立场所继续使用原值，未覆盖的场所使用新的公用费率。 |
| P1，Binance 永续开空错误地以标记价上限剔除较优的买盘；Bitget 永续用买一抬高了以标记价计算的公开卖出下限 | 按交易所和买卖方向应用保护，保留较优买盘和范围内的后续深度。Bitget 现货按现价，永续按标记价。两所均用买一溢价、第二档足额和越过下限的盘口核验。 |
| P2，飞书队列恢复投递时原机会可能已经过期 | 正文同时写明报价时间、有效截止时间与过期复核说明。 |

增量复核核对了费率和盘口修复树 `e3ab97ff`、后台公平配额修复树 `25291eda`，以及队列取消处理树 `8af149ba`。三家各查两个币、每次询价耗时五秒时，第三家等待一秒取得两个名额，峰值并发为四。两路复核确认所列问题均已关闭。

## 验证

- Windows 原生通过前后端类型检查、页面构建和 98 项相关测试，检查后台无页面运行、监控暂停及重启、设置冲突、限流、跨场所费率、充提身份、盘口时间、精度和最低充值。用登录后的 HTTP 接口、行情 IPC 与 SQLite 替身发件箱验证严格超过阈值才入队，去重跨重启保留。生产资源装载器读取全部 65 项前端资源。
- 桌面 1280 和手机 390 像素宽度使用 Windows Edge 验收。仅选 Gate、预算 1,000 USDT、阈值 300 bp，关闭页面后完成十轮扫描，替身飞书只收到 384.6 bp 的永续提醒。现货为 284.7 bp。独立费率改为现货 15 bp、永续 7 bp 后，结果为 27.955 与 38.044 USDT。未保存的预算和费率没有进入单币复核。停止、刷新与跨所复核参数均符合预期。页面没有横向溢出和 CSP 报错。
- 实际匿名读取 Ethereum 上同一地址的 LINK，Gate、Binance、Bitget 均取得链上买入报价及买入 Gas，两条路线均成功计算。Binance 同时核验现货深度事件与 REST 快照。以上为公开行情抽样。

本次送达验证使用替身飞书及本地发件箱。没有向真实机器人发送消息，没有访问交易账户或部署服务器。既有 Linux 符号链接与 systemd 行为由发布 CI 验证。
