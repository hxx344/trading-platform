# 链上折价自动扫描审查

2026-11-26，R2。基线为 `e5083d9`（v0.96.0），回退到该版本无需迁移配置或数据。范围覆盖 `src/chain-arb/` 的 Gate 目录、行情复用、扣费口径和扫描调度，以及行情 IPC、HTTP、页面、预览替身和相关测试。

## 独立审查

首轮审查树为 `ba271089`，增量树为 `970c71bc`、`95692a01` 和 `9f4d7e9f`。首轮核实三项 P1。

| 触发与影响 | 修复与验证 |
| --- | --- |
| Gate 上有中文代码的 BSC 代币可充值、交易，扫描和单币入口却跳过它们 | 目录和单币入口共用有界的 Unicode 字母、数字校验。URL 只编码一次，并核对原始代码、网络和合约地址。用中文币名贯通公开盘口和浏览器复核。 |
| 同币的现货盘口比永续旧 14.9 秒，新永续跟随现货提前到期 | 按每条路线自己的盘口、链上报价和生成时刻计算有效期。测试验证现货进入历史时，永续仍可保留至自身报价满 15 秒。 |
| 充值关闭或市场撤下后，另一条路线的资格与单币元数据缓存会使已失格的路线重新出现 | 目录保留逐路线资格并同步清退所有扫描条件下的失格行。第一次增量审查发现单币复核仍保留旧充值状态，现已重新读取该币元数据，并按最新有效扫描目录核对路线。实际扫描器和页面查询生成器覆盖充值关闭、永续市场撤下两种情况。 |

第二次增量审查复现了单币复核页停留十秒、目录缓存到期后重新显示已撤下永续的情况。复核查询现带有显式来源，每次取得有效目录后才展示路线；目录过期会刷新，目录不可用时返回错误。定向用例同时验证缓存过期、刷新失败以及手动查询原有的参数。

最终独立复核在相同场景下确认三项 P1 均已关闭，允许合入。没有遗留 P0、P1 或 P2。

## 验证

- Windows 原生通过 `pnpm check`、`pnpm build:web` 和 54 项后端与前端定向测试。覆盖预算、精度、Gas、买盘深度、路由分别到期、目录刷新、多组条件共享进度、限流恢复和登录后的 HTTP 到行情进程 IPC。生产页面加载器读入全部 65 个构建资源。
- Windows Edge 在 1280 和 390 像素宽度通过替身验收。1,000 USDT 预算时两路线以扣费后价差排序，调整永续额外成本后顺序反转。暂停期间停止查询，继续后恢复，过期行和单币复核符合预期。手机表格可横向滚动，页面无横向溢出。最终构建另验证中文机会带入 BSC、原始地址、正确编码的币名和自动 Gas。
- Gate 公开目录实测匹配 912 个币种与网络组合，其中 Ethereum 578 个、Arbitrum One 34 个、BNB Smart Chain 300 个。抽查 Arbitrum 前四个候选，扫描进度和失败计数正常；BSC 中文币名取得按量链上路由与 Gas，并读取 Gate 现货盘口。候选总数随市场而变。

实测限于公开行情。没有执行真实交易、划转或服务器部署。
