# 链上折价套利

## 币安实际充值地址与 WebSocket 行情

本次按 R3 扩展既有后台扫描。币安路线复用资产账本保存的只读连接，执行服务核对账户可充值的币、网络、完整合约和实际收款地址，用同区块的只读模拟实收量核算现货及永续净价差。行情服务用公开 WebSocket 查询现货交易对目录、交易规则、参考价格及两类市场各 100 档深度，订阅现货深度更新与永续标记价。现货深度快照用交易所推送的序号及时间校准；深度无法覆盖整笔数量、数据过期或缺少有效行情时跳过。公开钱包网络目录和 USD-M 产品目录通过 HTTPS 读取。[币安现货行情流](https://developers.binance.com/en/docs/catalog/core-trading-spot-trading/api/ws-streams/~)账户或行情证据缺失、过期、身份冲突或低于门槛时，按对应条件跳过排名或提醒。该范围覆盖账本、公开行情 IPC、排行和飞书队列，不增加交易或链上广播能力。回滚至 v0.103.0 后币安自动退出有效路线；不迁移账户、配置或发件箱。Bitget 仍待单独对接。

## 实际充值地址模拟（v0.101.2）

本次按 R3 核对 Gate 和 OKX 的资产账本连接与净收益。执行服务使用交易所返回的当前账户充值地址，在固定的对应链 RPC 上只读重放买入和转账，读取收款地址转账前后的代币余额差与该次 Gas，按此数量重新核对最低充值量、两类盘口和费用。RPC 会收到模拟所需的地址。地址、账户信息及签名不进入行情 IPC、页面、日志和飞书。行情路由服务只使用模拟买方。选中的地址不唯一、网络或合约不符、需备注、账户变更、报价过期或模拟失败时撤下候选。币安与 Bitget 暂缺账户地址核验，本次不产生这些场所的机会提醒。仅模拟，链上不签名、不广播，账本及配置无迁移。飞书发件箱自动增加可空的提醒键和受保护消息的发送时间。投递及重试前核对原报价和当前账户资格，旧版发件进程不能投递这些待发消息。回退到 v0.101.1 前先关闭后台提醒，避免恢复旧估算。

## 整笔成交、代币税与充值准入（v0.101.1）

新增 Gate 账本核验按 R3 审查。只在执行服务使用已保存的 Gate 连接，对已通过公开币链、盘口与模拟筛选的候选调用固定钱包读取接口，核对账户可用的目标网络及最低充值量。充值地址、API 密钥和签名不进入行情 IPC、页面、日志或飞书。换连接、最低额无效、网络不符或无法查询时撤回对应机会。此次不执行交易或划转。关闭后台提醒并回到 v0.101.0 即可回滚，账本格式不变。

本次修正行情测算、账户充值资格和飞书机会口径，覆盖单币、后台扫描与所有交易所。按配置的整笔 USDT 预算对同链同合约做只读兑换模拟，核对实际花费与接收余额，并与小额同向报价比较价格影响。转至交易所的可用数量另按普通转账模拟的实收量保守估算。现货和永续均须核实所选交易所、所选网络充值开放以及最低充值量。永续采用充值后在交易所卖出现货并在基差收敛时平空的情景，包含现货退出和两次合约交易的费用。失败、流动性不足或缺少必要证据的路线不进入机会榜和飞书。工作台无对应入口，沿用现有页面；无配置或数据库迁移。回退到 v0.101.0 会恢复原估算，回退前关闭后台提醒。

## 首版范围

在「链上」工作区按指定币种和 USDT 预算比较两条路线。链上用 KyberSwap 的指定金额买入报价，首批覆盖 Ethereum、Arbitrum One 和 BNB Smart Chain。交易所先接 Gate 的 USDT 现货和 USDT 线性永续。币种由链和 ERC-20 合约地址确定，交易所代码仅用于查目录。沿用行情监控的配置、设置页导入和命令行启用入口，不新增账户、密钥、配置迁移或常驻采集。

- 现货路线按预计到账数量逐档吃买盘，核对所选链的币种身份、充值状态与交易状态。结果是当前盘口下的估算，到账前价格可能变化。
- 永续路线按可覆盖的数量比较链上买入均价和开空均价，列出开仓基差。基差收敛情景单独列示，手续费、链上开销、资金费与离场成本须有明确口径。
- 同名异币、报价过期、盘口不足、上游不可用时展示具体原因。页面按需订阅单个币，离开后停止刷新。服务端只请求固定公开行情接口。
- R2，只读测算。回退版本 v0.95.0。工作台 7745181 的 `modules/monitor/app/perpetual-panel.tsx` 和 `server/perpetual-spot-transfer.mjs` 提供行情与链身份显示参考。工作台没有对应的链上买入页面。沿用现有页面组件与样式，使用两张独立结果卡，在手机上按现货、永续顺序阅读。

## 当前使用与测算

进入「链上 → 链上折价套利」，选择交易所、买入预算、费率和飞书阈值，打开后台扫描并保存。行情监控总开关和账本设置可在页面指引中找到。Gate、OKX 和 Binance 使用账本中已有连接。Gate 对通过公开检查的候选读取币种充值费、最低充值数量及可用的目标网络。检测到停充、同链同地址不唯一、最低额缺失、需备注或未能确认零充值费时，跳过该候选。Gate 查询充值地址时可能为首次使用的币种分配地址。账户读取只调用固定的 GET。执行服务只向对应链的模拟 RPC 发送收款地址，API 密钥与签名仅用于交易所接口。[Gate 钱包接口](https://www.gate.com/docs/developers/apiv4/en/wallet/)

链上按每份预算分别取整笔及 1% 小额 Kyber 路由，在同一已确认父区块用临时余额执行只读模拟。预算必须完整花出，以代币余额变化核实买入实收；对 Gate、OKX 和 Binance 使用当前选定链的账户充值地址，重放同一区块、同一笔买入及转账。该地址转账前后的余额差用于测算，包含依收款地址而异的代币税。按这次转账消耗的 Gas 计费。链上模拟不能确认交易所内部入账，等待充值期间盘口也可能变化。若每 USDT 实收较小额少 **超过 5%**，或模拟失败、报价过期，两个路线均不排名、不提醒。机会最长展示 15 秒，截止时间取参与测算的最早数据。[KyberSwap 路由 API](https://docs.kyberswap.com/developer-guide/aggregator-api/aggregator-api-specification/evm-swaps) · [以太坊只读模拟](https://ethereum.github.io/execution-apis/api/methods/eth_simulateV1/)

现货以转账后数量按交易步长取整，逐档吃符合卖价保护的买盘。永续要求同一数量在现货和合约两个市场都有足够深度，使用共同交易步长，按当前现货买一推算基差收敛时的平空价，并计入现货成交深度损耗。净收益扣除整个输入预算、估算的批准/买入/转账 Gas、一次现货卖出费、适用的永续开平仓手续费及自填的其他费用，尾数按零估值。资金费和未来平仓滑点仍未知。额外成本仅填尚未计入的费用。净收益率分母为整笔预算，阈值以 bp 计，严格超过才入飞书队列。

Binance 用官网充值网络目录核对费用和公开开关，再用资产账本签名查询所选账户的币链目录和该币、该网络的默认充值地址。两份目录的链、币种、完整合约、面额与充值状态须匹配，最低充值量取两者较高值。多个默认地址、需附言、地址重置、暂停或地址不能确认时，跳过该币链。账户目录含有余额，仅在账本读取时处理；行情进程、页面和飞书收取的地址字段是代币合约地址。只读数据验证方法见[币安钱包接口](https://developers.binance.com/en/docs/catalog/core-trading-wallet/api/rest-api/capital)。

手工查询同样需要实际地址模拟成功。额外成本留空时可查看毛差额，已填成本时可查看亏损或净收益。扫描只排名正净收益。OKX 账户接口包含历史地址，仅接受同链唯一选中的地址；该接口提供的合约末六位须与当前币链目录中的完整合约匹配。不显示实际充值地址。[OKX 充值地址接口](https://www.okx.com/docs-v5/en/#funding-account-rest-api-get-deposit-address)

## 自动扫描（v0.97.0）

自动扫描按 Gate 目录取得 Ethereum、Arbitrum One 和 BNB Smart Chain 的代币地址，在「链上折价套利」页按买入预算持续分批询价。每个候选复用单币入口的链上报价、Gate 身份、充提和盘口判定。按路线的扣费价差从高到低排列，现货和永续分别标识。在榜单上打开单币复核时，沿用金额和费率并重新取得报价。

扫描的建仓 Gas 采用 KyberSwap 对本次路由的报价估算，以输入 USDT 对应的美元估值换回 USDT。缺失此估算时该币不进入扣费榜。额外转账、退出等费用由操作者按路线设置，永续按基差收敛情景和两次合约费测算。排名分母为可成交数量对应的链上买入成本。页面会区分仍有效的机会、已过期的采样记录、无法测算和扫描进度。

本批为 R2。沿用原行情监控开关、设置导入和 IPC 拓扑，扫描进度保存在行情进程内存。页面有可见订阅时按需推进，离开后本批收尾。回退到 v0.96.0 无需配置或数据迁移。

每次最多查两个币链组合，各参数组共用启动间隔和并发上限；每份参数一轮覆盖所选网络的全部候选，部分名额用于复核此前发现的正价差。相同参数共用进度，行情开关代次变更后重新开始。目录由 Gate 币种、USDT 现货交易对和 USDT 永续 ticker 并集构成，每五分钟刷新。无现货交易或充值关闭时，仍可发现有同币永续的候选。多代码指向同链同地址、网络记录重复或合约地址缺失时跳过。

榜单只收录至少一条路线可测算、按该路线覆盖数量扣费后价差仍为正的记录。按量 DEX 路由已包含池内成交影响，再减去估算的买入 Gas、一次现货卖出费或两次永续交易费，以及手填的该路线额外成本。后者默认 0，转账 Gas、现货退出费用等可按需填写，资金费不计。每个报价最多有效 15 秒；过期发现移到「最近采样」，五分钟后移除。重新核验时变为负或无法测算的记录撤下。暂停后可查看此前采样；机会复核使用新盘口。

同一币种的两条路线独立到期，以各自 Gate 买盘和链上报价中较早的时间为准。目录支持中文币种代码。目录更新发现充值关闭或市场撤下时，所有扫描条件下对应的路线都会撤下，其余合资格路线继续报价。

从榜单打开单币复核后，每次刷新都会重新读取该币的充值、交易状态，并核对有效的市场目录。目录到期会重新获取；读取失败时页面显示原因。手动改选币种、网络或合约地址后，使用新身份单独查询。

## 后台扫描与交易所（v0.98.0）

用户在现有页面保存扫描预算、网络、交易所、费用和飞书阈值。行情监控服务按保存的设置自行运行，页面关闭与服务重启后继续工作。使用原有监控总开关、状态库及通知发件箱。按币种、链、地址、交易所与路线区分机会，只对新鲜且扣费价差严格高于阈值的结果提醒，正文标明净收益的币种及永续收敛假设。

本批优先接入 Binance，并接入 Bitget。Binance 官网钱包状态页的公开目录给出网络地址、充提及代币面额，Bitget 公共市场目录给出合约地址与充值条件。无法取得可靠身份、面额或盘口的路线不估算。交易所的公开行情留在行情层，飞书继续经现有通知服务发送。R2，只读市场数据、调度与提醒，无凭据或数据库结构变更。工作台没有对应的后台配置页，本版沿用现有价差扫描页和行情监控的启停交互。回滚到 v0.97.0 可继续按页扫描，无需迁移数据库。

首次升级后后台扫描默认关闭。在页面勾选交易所并保存启动，可按场所覆盖公用的现货和永续费率。阈值单位为 bp，100 bp 等于 1%；恰好等于阈值不通知。沿用行情飞书机器人，未单独配置时使用平台告警机器人；未配置机器人时仍可查看榜单。同一交易所、网络、代币地址和路线的飞书消息每 30 分钟最多入队一次，重启保留限频。切换合约价差监控总开关会暂停或恢复后台。扫描设置写入已有的 `monitor.sqlite`，每次服务重启从新行情开始。

币安现货盘口的 REST 快照没有成交簿更新时间，复核时结合对应交易对的公开深度推送和更新序号确认新鲜度。官网钱包网络目录的字段缺失、面额与链上代币不符时跳过，其他交易所独立运行。Bitget 使用普通 USDT 现货及 USDT 线性永续，按对应盘口、交易步长、买盘保护和最低充值量核验。[币安钱包网络状态](https://www.binance.com/en/network) · [币安现货深度推送](https://developers.binance.com/docs/binance-spot-api-docs/web-socket-streams#diff-depth-stream) · [Bitget 市场数据](https://www.bitget.com/docs/catalog/market/market-data)

## OKX 与可见入口（v0.100.0）

「链上 → 链上折价套利」常驻侧栏，未配置合约价差监控时提供设置指引。OKX 是后台扫描和单币复核的可选交易所；复用现有的逐所费率、扣费排名与飞书阈值。现货充值卖出和 USDT 线性永续开空按各自资格判断。已保存的交易所选择沿用原值。

R3，影响面包括资产账本只读连接、执行服务到行情服务的本机 IPC、市场身份、页面入口与告警。只在资产账本所在的执行服务读取已有 OKX 连接，以固定签名 GET 核实只读权限和币种网络。行情进程只接收短期有效的币种、网络、代币合约地址和充提条件，使用 OKX 公开产品目录及盘口。连接撤销、权限不可核实、目录过期或链地址不唯一时，停止输出受影响的 OKX 机会。验证使用虚构凭据及替身飞书，公开行情单独抽查。回退到 v0.99.0 前在扫描设置取消 OKX 及其独立费率；资产库与凭据格式无需迁移。

更新后在「链上 → 链上折价套利」勾选「OKX」与「启用后台扫描」，填写预算、阈值并保存。已有后台配置继续使用原交易所选择。页面提示行情监控尚未配置时，按页内指引到「设置 → 从工作台导入」启用行情监控。需要连接或更换 OKX 时，使用「资产 → 交易所连接」。后台按现有行情飞书渠道发送，同一路线沿用 30 分钟去重。

目录在同一连接下续期时保留条件未变的行情采样。更换连接或确认撤权后，后台撤下原账户的榜单、历史与进度。永续净收益按公开盘口和基差收敛计算，个人账户的保证金、开仓额度与资金费未计入。

执行服务从 OKX 的账户配置核实密钥仅有读取权限，再读取该账户的币种网络。目录覆盖 Ethereum、Arbitrum One 和 BNB Smart Chain。现货路线要求对应网络开放充值，链、合约地址和最低充值数量一致；有额外费用、标签或账户充值配额等尚不能完整测算的条件时跳过现货。已可靠确认代币身份时，充值关闭的币种仍可单独检查同币 USDT 线性永续。公开行情分别核对交易状态、买盘深度、限价保护、交易步长和市场单上限。净收益、阈值单位和永续收敛假设沿用上面的计算口径。详情见 [OKX 账户、资产和市场 API](https://www.okx.com/docs-v5/en/)。
