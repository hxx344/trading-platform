# 持仓对冲容差 0.5%（R3）审查记录

- 日期：2026-11-12
- 起因：用户实测启用 xau 配对，被接管检查以“两侧持仓不对冲”拦下（KORUUSD1 净多 0.21、XAGUSD1 净多 16.61 等）。用户说明持仓本就允许 0.5% 以内的偏差，ADL 也不应以净持仓为 0 判断。
- 用户决定：
  - 每个标的两个子账户合计的多空总量之差，不超过较大一侧的 0.5% 即视为对冲。
  - ADL 的选择是“0.5% 内不动，超出减到相等”。
- 改动：
  - `src/adl-contracts.ts` 新增 `hedgeGap` 与 `HEDGE_TOLERANCE_BPS`。
  - 接管检查（`src/service/takeover.ts`）与持仓面板“一致”（`src/positions.ts`、`src/page.ts`）都按容差判断，提示写出多、空总量与偏差百分比。
  - ADL 规划（`src/adl.ts` `planReductions`）：
    - 容差内的标的记为残差，不减仓，也不读交易规则。
    - 本事件或其父事件链上已发过批次的标的，不适用容差，减到相等。
  - 飞书完成通知（`src/service/feishu.ts`）列出残差。
- 等级：R3（改变 ADL 实盘减仓的触发与终止条件、启用检查）。
- 影响面：
  - 只改“是否需要减仓 / 是否算对冲”的判定。
  - 下单数量、批次上限、核对与撤单流程都不变；划转不受影响。
- 回滚：`install.sh --version v0.4.2`。数据库结构不变。
